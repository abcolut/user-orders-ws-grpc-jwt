# Order System (SQLite + WS + Auth + gRPC)

Система управления заказами с гибридным API: HTTP для основных операций и gRPC для внутренних вызовов, плюс real-time уведомления через WebSocket.

## Основные возможности

- **Регистрация и авторизация пользователей** с использованием JWT-токенов.
- **Управление заказами**: создание, обновление статусов, фильтрация по пользователю.
- **Валидация данных** на входе с помощью `go-playground/validator`.
- **Real-time уведомления**: при изменении статуса заказа WebSocket Hub рассылает событие всем подключенным клиентам этого пользователя.
- **Гибридный API**: 
  - HTTP API (порт 8080) для фронтенда/клиентов.
  - gRPC API (порт 50051) для внутренних сервисов или высоконагруженных клиентов.
- **Защита эндпоинтов** middleware-ом проверки JWT-токена.

## Архитектура и особенности реализации

- **Изоляция логики**: бизнес-логика вынесена в пакет `internal`, точка входа — в `cmd/server`.
- **Работа с контекстами**: все методы репозиториев принимают `context.Context` для корректной отмены операций и таймаутов.
- **Обработка ошибок**: ошибки БД и бизнес-логики возвращаются клиенту в структурированном виде (HTTP-коды или gRPC status codes), паники исключены.
- **WebSocket Hub**: централизованное управление подключениями и рассылка сообщений по user_id.

## Стек технологий

- Go 1.26
- SQLite (через `mattn/go-sqlite3`)
- gRPC + Protocol Buffers
- Gorilla WebSocket
- JWT (`golang-jwt/jwt/v5`)
- Валидация (`go-playground/validator/v10`)
- Управление зависимостями (`go mod`)

## Запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone <ссылка-на-твой-репозиторий>
   cd my_api


2.  Создайте файл конфигурации:

    ```bash
    cp .env.example .env

3. Установите зависимости:

    ```bash
    go mod tidy

4. Запустите сервер:

    ```bash
    go run cmd/server/main.go

    Сервер запустится на портах:

    HTTP: localhost:8080
    gRPC: localhost:50051
    
5.  Запустите gRPC-клиент для тестирования:

    ```bash
        go run cmd/client/main.go

## Структура проекта
    ```text
    my_api/
    ├── cmd/
    │   ├── server/      # Точка входа HTTP + gRPC сервера
    │   └── client/      # gRPC-клиент
    ├── internal/
    │   ├── api/         # HTTP хендлеры и роуты
    │   ├── db/          # Репозитории, модели, работа с БД
    │   ├── ws/          # WebSocket Hub и клиенты
    │   └── handlers/    # Логика JWT, регистрации, логина
    ├── proto/           # .proto файлы и сгенерированный код
    ├── templates/       # html файлы клиента
    ├── migrations/      # SQL-скрипты для БД
    ├── .env.example     # Шаблон переменных окружения
    └── Makefile         # Команды для сборки и запуска
